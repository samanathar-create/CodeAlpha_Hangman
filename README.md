# CodeAlpha Hangman Game

## About the Project

This project is a Python-based Hangman Word Guessing Game developed as part of the CodeAlpha Python Programming Internship.

The game allows players to guess a hidden word one letter at a time. The player has a limited number of incorrect guesses to find the correct word.

## Features

* Random word selection.
* Letter-by-letter guessing.
* Limited incorrect attempts.
* Displays guessed letters.
* Win and lose messages.
* Simple command-line interface.

## Technologies Used

* Python 3
* Python standard library (`random` module)

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python hangman.py
```

If your system uses `python3`, run:

```bash
python3 hangman.py
```

## How to Play

1. Run the Python program.
2. Read the hidden word's displayed blanks.
3. Enter one letter at a time.
4. Try to guess the word before running out of attempts.
5. The game displays whether you win or lose.

## Purpose

The purpose of this project is to practise Python programming, loops, conditional statements, strings, lists, and basic game logic.
